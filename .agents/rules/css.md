# REGOLA CSS: Design Tokens & Apple Luxury Minimalism

1.  **Strict Color Palette**: Devi utilizzare ESCLUSIVAMENTE le seguenti variabili CSS o le rispettive classi utility (es. Tailwind). Non inventare colori.
    * `--color-dominant`: #800020 (Bordeaux) - Uso: 60% (Sfondi, Deep Canvas).
    * `--color-secondary`: #FFFFF0 (Bianco Avorio) - Uso: 30% (Testi, Griglie, Bordi sottili, Icone).
    * `--color-accent`: #ffd700 (Oro) - Uso: 10% (Call to Action, Stati attivi, Dettagli Premium).
2.  **Borders & Shapes**: Usa bordi ultra-sottili (1px solid var(--color-secondary)). Evita bordi arrotondati eccessivi; mantieni un rigore geometrico tagliente ed elegante.
3.  **Typography**: 
    * Headings (H1-H6): Usa font Serif ad alto contrasto (es. Playfair Display o Cinzel).
    * Body: Usa Sans-Serif o Serif leggero ad alta leggibilità, con un "tracking" (letter-spacing) ampio per dare respiro al testo.
